# 高性价比装修指南

讲怎么在开工前把预算和需求定下来，怎么挑施工方、怎么看合同和报价单、增项是怎么多出来的。讲水电防水、拆改结构、燃气用电、甲醛通风这些出事代价最大的环节，怎么验收、怎么留证。也讲门窗灯光、厨卫柜子、收纳隔音这些住进去才知道值不值的部分。国标、部门规章和法院判例上的内容，按中国大陆的现行规定写。<br>
39 条建议，每条写明花掉什么、换回什么、证据有多硬。来源只引国家标准全文、住建和市场监管部门的官方文件、法院判决，以及期刊论文。

不用全做：这是按性价比排好的备选单，不是任务清单——挑走一两条就算数。

## 怎么读

- **不用全做**：这是一份按性价比排好的备选单，不是任务清单。挑走一两条就算数，剩下的放着，开工的时候再回来查。装修本来就是个取舍的过程，钱和时间都不宽裕时，先做每节排在前面的那几条。
- **想按条件挑**：打开[在线检索页](https://tbuffay.github.io/HowToRenovateBetter/)，可以按关键词、章节、证据等级来筛，也可以按「花不花钱、花多少时间、要不要毅力」这三样筛，几个条件能叠着用。页面上的内容直接取自 book/ 目录里的正文，正文一改，页面跟着改。
- **条目之间会互相指路**（「见第 5 节第 1 条」这种）：在检索页里，这种指路带一条虚线。点一下，就地显示被指的那条的标题和「说人话」。在 GitHub 上直接读正文点不动，但每处指路后面都写着指向什么（「见第 5 节第 1 条（拆墙先拿原始结构图）」）。不翻过去也知道说的是哪条。
- **想按顺序读**：每节内的条目按性价比从高到低排列，从每节前几条开始看就行。全书也大致按装修的先后顺序排：第 1 到 4 节是开工前，第 5 到 9 节是硬装，第 10 到 15 节是门窗厨卫和定制，第 16 到 19 节是住进去前要处理的，第 20 节是验收维权。
- **想离线看、想发给别人**：下载 [离线单文件 HTML](https://github.com/tbuffay/HowToRenovateBetter/releases/download/epub-latest/HowToRenovateBetter.html)，整本书连同检索和筛选都在这一个文件里，双击就开，不用服务器也不用联网，微信里也能直接传。谈装修的时候直接翻给对方看。
- **想打印或在手机上翻**：下载 [PDF](https://github.com/tbuffay/HowToRenovateBetter/releases/download/epub-latest/HowToRenovateBetter.pdf)，A4 排版，带目录页码和书签，每节另起一页。
- **想在 Kindle 或其他阅读器上读**：下载 [EPUB 电子书](https://github.com/tbuffay/HowToRenovateBetter/releases/download/epub-latest/HowToRenovateBetter.epub)，Kindle 用 Send to Kindle 发过去即可。
- **想记住、隔几天复习一遍**：下载 [Anki 牌组](https://github.com/tbuffay/HowToRenovateBetter/releases/download/epub-latest/HowToRenovateBetter.apkg)，用 Anki 打开就导入。一条一张卡，按节分成子牌组。正面是条目标题，背面是说人话、成本和证据等级。以后重新下载再导入一次，卡片内容会更新，复习记录不丢。
- **这四样都是正文每次更新后自动重新生成的**，下载链接固定不变；转发出去的那一份不会跟着更新，以在线版为准。
- **看不懂那串行话**：每条都有一行「说人话」。它把「收益」栏里标准条文和研究的写法，翻成「这一项能让你少花几千元」「漏到楼下要赔钱」这样的日常说法。它只用「收益」栏已经写到的内容，不添新数字。只看这一行就够拿主意。术语表在下面。
- **只想看结论最硬的**：在检索页里勾选证据等级 A，只留下有具体数字、出自国家标准强制条文或官方文件的 A 级证据的 19 条。

- **成本栏里的钱是粗略估计**，只用来互相比较，不要拿去引用。各地的工价和材料价差得远。

第 5 节第 1 条长这样：

```markdown
### 1. 拆墙之前先拿到房屋原始结构图，分不清哪面墙承重就别动
<!-- 成本标签: 钱=0 时间=中 毅力=否 收益=大 口径=安全 -->
- 成本：一次跑腿。向物业或开发商要房屋原始结构图和竣工图，通常不花钱。物业不给，就要求书面答复并留底。
- 说人话：承重墙和燃气管道不能自己动，没拿到设计方案就拆，是明令禁止的。花半天要一份原始结构图，是装修里最划算的一步。
- 收益：未取得原设计单位或者有相应资质等级的设计单位的设计方案，变动建筑主体和承重结构，属于禁止行为。拆改燃气管道和设施未经燃气管理单位批准，同样不得进行。
- 证据等级：A
- 来源：《住宅室内装饰装修管理办法》（中华人民共和国建设部令第 110 号，2002 年 3 月 5 日发布，2011 年住房和城乡建设部令第 9 号修正）第五条第一项、第六条第四项。https://www.gov.cn/zhengce/2002-03/05/content_5712023.htm ；住房和城乡建设部 https://www.mohurd.gov.cn/gongkai/zhengce/gzk/art/2022/art_17337_763893.html
- 备注：建筑主体指屋盖、楼盖、梁、柱、支撑、墙体、连接接点和基础等；承重结构指把自重和外力传到地基的主要构件，包括承重墙体、柱、楼板、梁等（同办法第五条第二款）。受益人主要是你自己家；帮父母家或朋友家看房子时同样适用，但别替人签字、别替人垫钱。
```

## 四种资源

这本书想帮你留住的不只是钱，一共四样东西：

- **钱**：同样的效果少花钱，别为看不懂的报价单和事后冒出来的增项付账
- **时间与精力**：少返工、少跑腿、少跟工人来回扯，把盯工地的日子压到最短
- **健康与人身安全**：别让甲醛、燃气、漏电、拆错墙这类事伤到自家人
- **人身自由**：不因为不知道一条红线，把自己送进拘留所或者被告上法庭

每一条建议都回答两个问题：要花掉什么（钱 / 时间 / 精力 / 毅力），能换回什么（省下的钱 / 省下的时间与精力 / 健康与人身安全 / 法律上的自由与保障）。条目按性价比排，不按类别排，也不按施工顺序排：几乎不花什么成本、换回的好处又大的，放在最前面。

**一条建议的好处落在谁身上，是分档的。** 按「这份好处将来有多大可能回到你自己身上」从高到低：① **你自己家**；② **父母和子女家**（直系亲属）；③ **朋友、同事和其他亲属家**——互惠关系，帮出去的将来可能回来；④ **陌生人**——最低一档，但不是零：回报的概率小，而且你不了解对方是什么人，还有被讹、被反咬、被报复的一面。不同档不合并计算，写到第 ④ 档时好处和风险一起写。

装修这个场景里，第 ② ③ 档尤其常见：帮父母看报价单、给朋友家盯几天工地。本书这类条目一律按这个顺序写——先写落在自己家身上时该怎么做，再写帮别人时的差别，重点是自保动作和免责条款（不当场替人签字、不替人垫钱、不替人担保），并在备注里点明这条的收益主要落在哪一档。

钱的数字、时间精力的数字、安全后果和法律后果，各算各的，不互相折算。这四样对应检索页上那四个「换回什么」，彼此之间不比大小。

## 证据分级

每条建议都标注证据等级：

| 等级 | 含义 |
| --- | --- |
| A | 有具体数字或明确条文可查：国家标准的强制条文、住建与市场监管部门的规章文件、官方统计与监管抽查数据，或者期刊论文（随机分组试验、队列研究、荟萃分析） |
| B | 有官方文件或标准支撑，但具体数字由地方或企业自定、各地不一；或者证据来自小样本、单一来源、单起案例 |
| C | 作者自己的经验，或者大家公认的做法，没有直接的文件或文献 |

全书 39 条中 A 级 19 条、B 级 11 条、C 级 9 条，另有 0 条标注了争议、4 处标注了 TODO 待核实。有争议的 A/B 级条目会标注「争议」并列出反方证据。所有来源只引原始文献（国家标准全文、住建部与市场监管总局等部门文件、国家统计局与各级消协的统计、人民法院判决书，或期刊论文附 DOI），不引二手转述，也不引装修公司的营销内容。

A 级只说明「有具体数字或条文、出处可核」，不说明这个数字一定适用于你家。A 级里既有随机分组的试验，也有只跟踪记录、不分组的研究，后者分不清是这件事起了作用，还是做这件事的人本来就不同。哪一种看收益栏：写着「随机分成两组」的是前者，写着「只记录、不分组」的是后者。标准和法规类条目的 A 级，指的是引到了条文原文。

## 性价比档

证据等级只回答「这个数字可不可信」，不回答「这件事值不值得做」。所以每条还另外标了两样：收益量级（好处有多大）和口径（换回的是哪一类东西）。检索页拿这两样加上三项成本，合出一个性价比档：

| 维度 | 取值 | 怎么定的 |
| --- | --- | --- |
| 口径 | 换钱 / 换时间精力 / 换健康与安全 / 换人身自由 | 看这条主要换回的是什么。**不同口径之间不做比较**，「省 8000 元」和「少一次燃气泄漏」不在一把尺子上，没法分高下 |
| 收益量级 | 大 / 中 / 小 | 尽量照着条目自己的「收益」栏，按事先定好的界线套，不凭感觉：换钱看金额（万元级为大，数百到数千元为中，几十元为小）；换时间精力看省下多少（每天省出小时级为大，每周小时级为中，只省一次的为小）；换健康与安全看后果（避免伤亡或重大健康损害为大，避免可恢复的伤害为中，只是不舒服为小）；换人身自由看后果（避免刑事责任为大，避免拘留或行政处罚为中，避免民事纠纷为小） |
| 性价比 | 极高 / 高 / 一般 | 好处大、三项成本又全是零 = 极高；好处大、成本不高，或者好处中等、成本为零 = 高；剩下的 = 一般 |

全书 39 条中性价比极高 8 条（21%）、高 23 条（59%）、一般 8 条（20%）。中间那档条数多是有意的：底下的收益量级本来就只分大、中、小三级，再往细里切就是装出来的精确。

**这一档是作者自己的判断，不是证据**，按本书的标准它本身只算 C 级；它和证据等级是两回事，谁也不影响谁。一条可以证据是 A 级、性价比却只算一般（标准的强制条文写得清楚，但照做要花上万元），也可以证据只有 C 级、性价比却极高（开工前把每个房间要几个插座数一遍）。「一般」不等于不该做——全书的条目都是建议做的，只是这一档得你自己掂量那笔花销值不值。
