# 01-01 先定总预算，再按比例分项

## 引用

无直接文献。本条是装修业主的普遍做法和作者经验，按 C 级处理。

## 关键内容

- 动作：开工前先定一个能拿出来的总预算，再按比例分到硬装、主材、家电、家具几块，最后留一笔不参与分项的预留金专接增项。
- 预留金比例：正文写「常见做法是总数的一到两成」。

## 为什么标 C 级

- 官方文件（《住宅室内装饰装修管理办法》等）没有规定总预算该怎么分，也没有规定预留金留多少。国家标准里没有对应数字要求，所以按 C 级处理。
- 唯一能挂上规章的一点：合同要写明装饰装修工程价格以及计价和支付方式、时间，见《住宅室内装饰装修管理办法》第二十四条第五项（原文见 04 节相关条目的核实记录）。这一条只说明合同里要写价格，不能推出「总预算该怎么分」的比例，所以本条整体仍是 C 级。

## 收益量级为什么定「大」（金钱口径）

- 阈值：金钱口径万元级为「大」。
- 判断依据：预留金按总预算的一到两成留，普通住宅装修的总预算通常在十几万到几十万元，一到两成就是数千元到数万元。这一笔加上总量控制挡住的超支，落在万元级，所以定「大」。这个量级是按条目自己的收益栏机械套的，不是凭感觉。

## 待核实

- 「一到两成」是经验值，官方文件没有给比例，各地做法不一。备注已写明「标准没有给数字」。
