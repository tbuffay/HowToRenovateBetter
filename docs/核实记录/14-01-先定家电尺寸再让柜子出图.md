# 14-1 先定家电型号和尺寸，再让柜子出图

## 这一条要核什么

- 嵌入式电器（洗碗机、冰箱、洗衣机、烤箱）的「安装尺寸」和「外观尺寸」不是一回事。
- 柜体按厂家的安装尺寸预留位置，顺序反了要改柜子或者退电器。
- 有没有官方文献能给出可引用的数字。

### 没有引用的数字

正文里「改一次柜体通常几千元、工期往后拖一个月」来自装修行业通行说法，没有官方统计或标准出处，属作者经验，故整条记 C 级。各地工价差得远，这个数字只用来说明量级。

## 结论

- 证据等级：C
- 理由：动作（先定型号、把安装尺寸写进柜子图纸）来自柜体和家电行业的通行做法；能找到的唯一相关国标是推荐性标准，原文未取到，也没拿到可引用的数字。
- 正文不写任何尺寸数字，只写动作和量级。
