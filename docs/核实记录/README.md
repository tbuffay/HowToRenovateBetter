# 核实记录

这里放每条来源的核实过程：这一条的关键数字是在哪份文件哪一条里找到的，原文怎么写的，抓取日期是哪天，有没有抓不到原文而标了 TODO 的地方。

## 为什么要有这个目录

本书只引原始文献——国家标准全文、住建和市场监管部门的规章与公告、国家统计局与各级消协的统计、人民法院判决书、期刊论文。这些来源有个共同的问题：链接会失效，条款号会因修订而变动，地方的执行口径还会不一样。只把链接写进「来源」栏，过两年就没人能核对当初引的是哪一句。

所以每条都留一份核实记录，写明：

- 关键数字或条文对应的原文句子，逐字抄下来
- 出处（文件名、标准号、条款号、发布机构、发布日期）
- 抓取或核对的日期
- 反复核对仍然找不到原文的部分，写「待核实」而不是猜

## 命名

一条一份文件，文件名是「节号-条号-短名.md」，比如 `05-01-拆墙先拿原始结构图.md`。同一条目多次补充证据时，追加在同一份文件里，不另开新文件。

## 抓不到原文的情况

- 政府网站挂了或者改版：先在同机构官网找新地址，找不到就用 web.archive.org 的存档，并在来源栏括号里注明「原页面已下线，链接为某年某月某日的网页存档」。
- 标准全文要付费或必须登录才能看：只写标准号和条款的出处置，正文里不写具体数字，备注写明「标准原文未取到，数字待核实」。
- 地方口径：写明是哪个地方的文件，不要写成全国通用。
