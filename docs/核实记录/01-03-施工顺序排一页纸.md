# 01-03 把施工顺序排成一页纸

## 引用

无直接文献。本条是装修施工的通行顺序和普遍共识，官方文件没有规定整体的施工顺序，按 C 级处理。

## 关键内容

- 动作：开工前把拆改、水电、防水、瓦工、木工和定制柜复尺、油漆、安装按先后排成一页纸，贴在工地上。
- 理由：从前三步（拆改、水电、防水）做完就被后面的工序盖住，之后再改就得砸开重做；定制柜要等墙面和地面做完才复尺。

## 为什么标 C 级

- 国家标准和住建部规章没有给出住宅室内装修的整体施工顺序。个别环节有规定，但它们各自属于后面的节：例如《住宅室内装饰装修管理办法》第八条要求「改动卫生间、厨房间防水层的，应当按照防水标准制订施工方案，并做闭水试验」，只卡住防水这一环，推不出整条顺序，所以本条整体按 C 级处理。

## 收益量级为什么定「中」（金钱口径）

- 阈值：金钱口径数百到数千元为「中」，万元级为「大」。
- 判断依据：顺序排错的典型后果是返工一个房间（砸开、重做防水、重铺面层），再搭上重买材料和工期。这个量级通常落在数千元，够不上万元级，所以定「中」，不用「大」。这里数字不足以机械套阈值，是按返工范围判断的，理由记在此处。

## 待核实

- 工期长短受气候和材料到货影响，各地和各工种不一样，标准没有给数字。备注已写明。
