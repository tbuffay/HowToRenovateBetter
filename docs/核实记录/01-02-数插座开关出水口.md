# 01-02 数插座、开关、出水口，列需求清单

## 引用

《住宅项目规范》GB 55038-2025 第 7.4.5 条、表 7.4.5。

## 关键条文原文

第 7.4.5 条：

> 住宅的电源插座均应采用安全型插座，卫生间设置的电源插座尚应加设防止水溅的措施。每套住宅电源插座的设置要求和数量应符合表 7.4.5 的规定，布置洗衣机、冰箱、排油烟机、排风机、电/燃气热水器、空调器处，尚应加设 1 个专用单相三孔电源插座。

表 7.4.5 每套住宅电源插座的设置要求及数量（逐格抄录）：

| 名称 | 设置要求 | 数量（个/间） |
| --- | --- | --- |
| 起居室、兼起居的卧室 | 单相两孔、三孔电源插座 | ≥3 |
| 卧室 | 单相两孔、三孔电源插座 | ≥2 |
| 厨房 | 单相两孔、三孔电源插座 | ≥3 |
| 卫生间 | 单相两孔、三孔电源插座 | ≥1 |

同章相邻条文（同一份 PDF 抄录，正文未引用，留档备查）：

- 第 7.4.4 条：住宅照明回路、空调电源插座回路、电热水器等 2kW 及以上的用电设备回路、厨房内的电源插座回路、其他功能用房的电源插座回路应分别设置。
- 第 7.4.6 条：年预计雷击次数大于 0.25 的住宅建筑应按不低于第二类防雷建筑物采取相应的防雷措施。其他可能发生地闪地区的住宅建筑，应按不低于第三类防雷建筑物采取相应的防雷措施。
- 第 7.4.7 条：进出住宅建筑的金属管道应与住宅建筑接地装置做等电位联结。装有固定浴盆或淋浴器的卫生间应设等电位联结作为附加防护。
