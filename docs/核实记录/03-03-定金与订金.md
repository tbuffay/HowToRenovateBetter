# 03-03 定金与订金

条目：分清定金和订金，定金最多写合同额的 20%（第 3 节第 3 条）
核实日期：2026-10-09

## 一、定金规则

出处：《中华人民共和国民法典》第五百八十六条
链接：https://tjca.miit.gov.cn/zwgk/zcwj/flfg/art/2020/art_20cf1a2e1b854924b5caa744c8045d1f.html

原文：

> 第五百八十六条
> 当事人可以约定一方向对方给付定金作为债权的担保。定金合同自实际交付定金时成立。
> 定金的数额由当事人约定；但是，不得超过主合同标的额的百分之二十，超过部分不产生定金的效力。实际交付的定金数额多于或者少于约定数额的，视为变更约定的定金数额。

对应条目「收益」栏：20% 上限、超过部分不产生定金效力、定金合同自实际交付时成立，三处都能在这一条里逐字对上。

## 二、定金罚则

出处：《中华人民共和国民法典》第五百八十七条

原文：

> 第五百八十七条
> 债务人履行债务的，定金应当抵作价款或者收回。给付定金的一方不履行债务或者履行债务不符合约定，致使不能实现合同目的的，无权请求返还定金；收受定金的一方不履行债务或者履行债务不符合约定，致使不能实现合同目的的，应当双倍返还定金。

对应条目「收益」栏：「给付定金的一方不履行债务、致使不能实现合同目的的，无权请求返还定金；收受定金的一方不履行债务、致使不能实现合同目的的，应当双倍返还定金」。

## 三、相邻条文（备查，未写进正文）

同法第五百八十八条：当事人既约定违约金，又约定定金的，一方违约时，对方可以选择适用违约金或者定金条款。

## 四、「订金」没有法条依据这一半

《民法典》第五百八十六条、第五百八十七条只规定「定金」，全文没有给「订金」下定义，也没有给「订金」设罚则。条目「收益」栏写的「订金只算预先支付的钱」是从这一点推出来的实务做法，**不是条文原文，按 C 级看**。备注里已写明：定金那部分是本条的 A 级，订金那部分按 C 级处理。

因此本条「证据等级」标 A，覆盖的是定金的一半；订金的一半只有 C 级，未单列条目。

## 六、成本标签的定法

`钱=0 时间=少 毅力=否 收益=中 口径=金钱`

- 钱：签约前看清一个字、算一下 20% 的上限，不花钱。定为 0。
- 时间：一次核对，顺手。定为少。
- 毅力：做一次就完。定为否。
- 口径：定金罚则多拿回的是钱。定为金钱。
- 收益：定金常见是数千元级，定金罚则带来的差别是「多拿回一份定金」，落在「数百到数千元为中」这档，定为中。合同额大时定金可以到万元级，量级会升到大；这里按常见的数千元定。
